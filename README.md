# 超级搜索引擎 Super Search Engine

一个自带 DeepSeek / 硅基流动 API Key 的 Android AI 工作台。

官方手机版有每日额度，也不能填自己的 API Key；这个 App 换了一种方式：

- 用你自己的 Key；
- 不买 App 会员；
- 没有应用层每日额度；
- 费用直接按模型厂商官方账单走。

> 不是破解，也不是永久免费。需要自备 API Key，模型调用费用由厂商收取，且受厂商账户余额和速率限制。

## 功能

- DeepSeek / 硅基流动双服务商，Key 分开加密保存
- 多轮聊天、64K / 256K / 960K 上下文模式
- 联网搜索、来源引用、内置浏览器、网页读取与追问
- 拍照 / 相册识图
- 图像生成、图像编辑、首尾帧视频
- 语音合成、声音克隆（需厂商实名认证）
- 生成前费用估算
- 图片 / 视频 / 音频导入系统相册
- 本地存储管理、更新包缓存清理
- 无广告、无账号体系

## 为什么做这个

手机版 AI 每天聊几句就限额，想接自己的 API Key 又没有入口，开会员也未必够用。

所以做了超级搜索引擎：把官方 API 能力接回手机，聊天、搜索、网页读取、识图、生图和创作都在一个 App 里完成。

它不卖会员，也不绕过官方额度；只是把“买 App 会员”换成“按自己的 API 用量付费”。

不是免费无限，是把选择权还给用户。
